> **一句话**：一个合成 × 放置 × 回合制 RPG 的微信小游戏——你作为后勤官，生产装备、合成升级、武装勇士，向魔王城推进；未收藏的勇士阵亡将永久消失、装备全毁。

## 30 秒玩法

- **生产**：花金币在格位上随机产出 1 级装备（9 品类：剑/刀/弓/盾/头盔/盔甲/靴子/戒指/护符，六属性：攻击/血量/防御/速度/暴击率/穿透）
- **合成**：同类型同等级两件合成升 1 级，最高 Lv8（=128 件 1 级），属性每级翻倍
- **配备**：把装备拖给勇士（6 部位槽：主手/副手/头/身/腿/饰品）
- **讨伐**：回合制自动战斗——按速度排序行动队列，魔物索敌规则（血量最低 3 个随机攻击）；胜利推进魔王城关卡
- **经营**：城镇挂机税收（Lv 持续升级）、酒馆招募（冒险者幸存 6 次晋升勇士）、熔炉回收
- **死亡惩罚**：未收藏勇士阵亡 → 永久消失 + 装备全毁；收藏勇士可"看广告"复活（演示按钮）

## 实现要点

- 策划案装备数值表逐条落地：剑 +12 攻 / 刀 +15 攻 +8% 暴击 / 弓 +10 攻 +8 速 / 盾 +30 血 +8 防 / 头盔 +25 血 +5 防 / 盔甲 +20 血 +10 防 / 靴子 +10 血 +2 防 +10 速 / 戒指 +5 血 +5 攻 +8% 暴击 +3% 穿透 / 护符 +5 血 +5 防 +1 穿透
- 战斗规则实现：速度排序行动队列、暴击/穿透伤害、血瓶回血、索敌规则
- 经济闭环实现：税收指数成长、招募定价、收藏位上限（10 个）、广告复活
- 存档：localStorage 自动读档
